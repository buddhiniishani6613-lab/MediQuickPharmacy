# MediQuick Pharmacy 

**MediQuick Pharmacy** is a web-based Online Pharmacy Management System developed to provide convenient and accessible pharmacy services.

The system allows customers to browse products, manage shopping carts, place orders, and upload prescriptions. It also provides an admin panel to manage pharmacy operations.

## Features

- Customer Registration and Login
- Browse and Search Products
- Shopping Cart Management
- Order Management
- Prescription Upload
- Customer Dashboard
- Admin Dashboard
- Product and Category Management
- Inventory Management
- Customer and Staff Management
- Prescription Management
- Reports and Notifications

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- PHP
- MySQL
- phpMyAdmin
- XAMPP

## Installation

1. Install [XAMPP](https://www.apachefriends.org/).
2. Download or clone this repository.
3. Extract the project into the `htdocs` folder.
4. Start Apache and MySQL from XAMPP.
5. Create a MySQL database named `MediQuickPharmacy`.
6. Import the provided SQL database file.
7. Configure the database connection in `config/database.php`.
8. Open the website in your browser:

```text
http://localhost/MediQuickPharmacy/
```
